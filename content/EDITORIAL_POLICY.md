# 海外内容运营日报抓取与筛选规则

## 目标读者

海外内容运营岗位。日报只回答：

> 今天发生了什么，会改变我今天或本周的平台运营、选题、达人合作、素材制作、投放或内容电商动作？

物流、货运、仓储、支付、关税、企业开店和一般市场扩张不是默认选题。只有直接改变内容发布、达人带货、广告投放或平台转化时，才可作为辅助背景。

## 六类信息

1. 平台动作：TikTok、Instagram/Meta、YouTube、Google、Amazon 等平台当天发布或生效的产品、算法、政策和流量入口变化。
2. 内容趋势：当天快速上升的内容形式、话题、叙事、搜索行为和区域文化表达。
3. 达人/KOL：创作者资格、商业内容披露、联盟佣金、授权、Creator Marketplace、直播权限与合作机制。
4. 广告投放：广告产品、素材规则、数据回传、归因、Smart+/GMV Max、搜索广告和 ROAS 优化。
5. 内容电商：TikTok Shop、直播、短视频挂车、商品卡、联盟带货、大促和内容到成交的机制变化。
6. 品牌案例：当天出现且能拆出明确内容打法的海外品牌案例；普通开店、融资或产品发布不自动入选。

## 全球滚动时间窗

- 报告归档日期按 Asia/Shanghai，但不再要求消息的原始日期必须与北京时间同一天。
- 每天北京时间 09:30 发布唯一的网页晨报；21:30 仅做后台预采集，不更新网页、不写日归档，也不触发 GitHub Pages 发布。
- 21:30 将亚洲当天、欧洲白天和北美早间的候选保存到本地 `content/pending/next-morning.json`；次日 09:30 再补查夜间与北美工作时段，并与晚间候选合并。
- 晨报事实窗口固定为“上一日 09:30（不含）—当日 09:30（含）”。`已核验事实`必须在该窗口内发布、生效或实际发生；不因来源当地日期显示为“昨天”而丢弃。
- 晚间预采集失败、文件缺失或日期不匹配时，09:30 必须自行回溯完整 24 小时；允许最多扩展到 26 小时防止边界漏抓。
- 必须保留来源页面的原始发布日期/时间和时区（若页面提供），并换算北京时间用于去重与窗口判断；只有日期没有时间时，标明“来源仅披露日期”。
- 页面更新时间、搜索结果日期和转载日期不能替代官方公告日、实际事件日或生效时间。
- 只标注到月份、季度或“近期更新”且无法核验具体日期的内容，不得进入今日核心。
- 近7—14天仍在生效的重要规则只能作为“背景跟踪”，必须写出原始公告日和生效日，不得进入“今日核心”。
- 当前扫描窗口可靠信息不足时少发或不发，不用窗口外旧闻补数量。

## 主线与兜底结构

两种信息不是平行模块，而是严格的先后关系：

1. `已核验事实`：官方公告、平台规则、品牌原始发布或可独立验证的事件；适用“当天性硬门槛”。
2. `行业雷达`：仅当北京时间当日累计 `已核验事实` 为 0 条时才启动。来源可以是国内公众号、海外创作者、独立媒体、行业通讯或社媒账号近期发布、且直接与海外内容运营相关的可执行信号，但不能把其判断写成平台已确认的事实。

只要当天存在 1 条或以上 `已核验事实`，当天就只发布已核验事实，即使最终只有 1 条；不得再加入行业雷达补足数量。同一日报禁止混合两种 `signal_type`。

行业雷达必须同时保留原文链接、作者/媒体名称、页面或帖文具体发布日期、原话所指的平台/市场和可执行价值；没有具体日期、只有截图、转载链或营销软文的一律不用。标题和摘要应使用“观察到”“报道/分析指出”“待官方验证”等表述，并将 `confidence` 标为“行业雷达／待交叉验证”或更准确的风险说明。

### 行业雷达时间与去重

- 常规候选窗口为晨报截止时间前 48 小时，优先最近 24 小时发布的内容。
- 只有已核验事实为 0、且过去 48 小时也没有合格雷达时，才可扩展到 72 小时；72 小时候选最多采用 1 条，并标注“补录”。超过 72 小时一律排除。
- 启动行业雷达不等于必须发布；候选不够强时仍可发布 0 条。
- 以“平台/品牌 + 功能或事件 + 市场 + 核心变化”生成 `event_key`。同一事件被公众号、海外媒体和创作者重复报道时只做 1 张卡片，其他链接仅作佐证。
- 每条保存 `source_published_at`、`source_timezone`、`first_seen_at`、`event_key`。已展示事件 14 天内不重复，除非出现官方确认、正式生效、新增市场、结果数据或规则实质变化。
- 行业雷达是否启动只在 09:30 合并完整 24 小时事实窗口后判断。21:30 可以暂存雷达线索，但不得发布，也不得提前认定次日需要雷达。

## 搜索顺序

1. 官方源：TikTok Newsroom、TikTok For Business、TikTok Shop Academy/Policy Center、Meta Newsroom/Business Help、YouTube Official Blog/Help、Google Ads & Commerce Blog/Help、Amazon Ads/Creator 官方更新。
2. 高质量行业源：用于发现当天信号和补充影响分析。
3. 中文公众号、社群和二手文章：只作线索雷达；必须回查官方页面、后台通知或可验证的一手证据。

行业雷达搜索只在完成官方源和品牌原始公告搜索、且候选表中确认 `已核验事实 = 0` 后启动。

## 品牌原始公告抓取策略

不逐个穷举所有品牌官网。采用“官方源池 + 当日触发 + 原文回查”：

1. 建立与内容运营强相关的动态品牌源池，覆盖奢侈品、美妆、服饰、消费电子、食品饮料、DTC 与内容电商品牌，并兼顾中国及北美、欧洲、亚太、中东、拉美品牌；不固定只看 LV、Gucci 等头部品牌。
2. 每天用品牌案例关键词和当天完整日期检索品牌 Newsroom、Stories、Press、Campaign、Collaboration、Creator、Social、TikTok、Instagram、YouTube、Live、Shop 等页面及品牌官方社媒账号。
3. 用行业媒体、广告营销媒体、公众号和创作者内容发现品牌线索后，必须回查品牌官网、官方账号、合作平台或代理商原始案例页；回查成功才可进入 `已核验事实`。
4. 只保留能拆解出内容策略的动作，例如全球/区域内容战役、创作者合作、平台首发、文化本地化、社媒账号策略、直播/内容电商、内容 IP 和可验证的素材/投放机制。普通新品、门店开业、代言官宣和品牌公关稿默认排除，除非包含明确的跨市场内容运营方法。
5. 源池按历史归档动态更新：连续出现高价值案例的品牌提高检查频率；长期只有产品或开店稿的品牌降低频率。行业雷达发现的新品牌可进入后续观察池，但不因此自动升级为事实。

每次扫描至少同时搜索：

- 平台名 + `update / policy / creator / ads / shop / live` + 扫描窗口覆盖的来源当地日期。
- 平台名 + `规则 / 算法 / 达人 / 广告 / 直播 / Shop` + 扫描窗口覆盖的来源当地日期。
- 美国、欧洲、东南亚、中东和拉美的区域语言关键词。

## 入选顺序

每条候选先过当天性，再判断：

- 岗位相关性：是否直接影响内容运营动作。
- 紧迫性：是否需要今天调整账号、内容、达人或广告。
- 可执行性：能否给出明确的检查或测试动作。
- 来源强度：官方原始来源优先；二手信息不能单独支撑高置信度结论。
- 来源多样性：同一平台或同一官方来源原则上最多占今日核心的 2 条；超过 2 条必须分别属于当天独立发生的重大事件，并明确说明集中原因。
- 新颖性：是否未在历史日报覆盖，或出现新的生效/落地证据。

## 强制排除

- 纯物流、货运、海外仓、清关和支付新闻。
- 普通门店开业、加盟、融资、组织任命和泛市场扩张。
- 只有“全球化”“出海”“跨境”等关键词但不影响内容工作的文章。
- 搜索结果当天出现、实际事件发生在更早日期的旧稿。
- 没有原始依据的“算法大改”“流量暴涨”“平台内部消息”。

## 发布闸门

- `content/latest.json` 的 `report_date` 必须等于北京时间当天。
- 晨报应记录 `edition=morning`、`scan_window_start` 和 `scan_window_end`；条目应记录 `source_published_at`、`source_timezone`、`first_seen_at` 和 `event_key`。晚间预采集文件不属于已发布日报。
- 每条核心资讯必须包含事件日期/状态、类别、行动建议、来源和置信度。
- 每条还必须包含 `signal_type`，只能是 `已核验事实` 或 `行业雷达`。
- 同一日报中所有条目的 `signal_type` 必须一致；只要存在已核验事实，就禁止发布行业雷达。
- 未通过当天核验时，网站构建失败并保留上一期可靠页面。
- 当天没有任何条目通过核验时，允许发布 0 条，并在页面明确说明“今日无通过核验的核心资讯”；禁止用背景跟踪填入核心卡片。
- 每天将完整 `content/latest.json` 复制为 `content/history/YYYY-MM-DD.json` 并随提交发布；季度最后一天生成 `content/reviews/YYYY-QN.json`，12 月 31 日另生成 `content/reviews/YYYY-year.json`，基于历史归档总结类别、市场、来源、可复用动作与证据边界。
