# 海外内容运营日报抓取与筛选规则

## 目标读者

海外内容运营岗位。日报只回答：

> 今天发生了什么，会改变我今天或本周的平台运营、选题、达人合作、素材制作、投放或内容电商动作？

物流、货运、仓储、支付、关税、企业开店和一般市场扩张不是默认选题。只有直接改变内容发布、达人带货、广告投放或平台转化时，才可作为辅助背景。

## 六类信息

1. 平台动作：TikTok、Instagram/Meta、YouTube、Google、Amazon 等平台当天发布或生效的产品、算法、政策和流量入口变化。
2. 内容趋势：当天快速上升的内容形式、话题、叙事、搜索行为和区域文化表达。
3. 达人/KOL：创作者资格、商业内容披露、联盟佣金、授权、Creator Marketplace、直播权限与合作机制。
4. 广告投放：广告产品、素材规则、数据回传、归因、Smart+/GMV Max、搜索广告和 ROAS 优化。
5. 内容电商：TikTok Shop、直播、短视频挂车、商品卡、联盟带货、大促和内容到成交的机制变化。
6. 品牌案例：当天出现且能拆出明确内容打法的海外品牌案例；普通开店、融资或产品发布不自动入选。

## 当天性硬门槛

- 报告日期按 Asia/Shanghai。
- 核心资讯必须满足至少一项：官方公告发布于当天；规则或功能于当天生效；事件实际发生于当天。
- 页面更新时间、搜索结果日期和转载日期不能替代事件日期。
- 只标注到月份、季度或“近期更新”且无法核验具体日期的内容，不得进入今日核心。
- 近7—14天仍在生效的重要规则只能作为“背景跟踪”，必须写出原始公告日和生效日，不得进入“今日核心”。
- 当天可靠信息不足时少发或不发，不用旧闻补数量。

## 搜索顺序

1. 官方源：TikTok Newsroom、TikTok For Business、TikTok Shop Academy/Policy Center、Meta Newsroom/Business Help、YouTube Official Blog/Help、Google Ads & Commerce Blog/Help、Amazon Ads/Creator 官方更新。
2. 高质量行业源：用于发现当天信号和补充影响分析。
3. 中文公众号、社群和二手文章：只作线索雷达；必须回查官方页面、后台通知或可验证的一手证据。

每天至少同时搜索：

- 平台名 + `update / policy / creator / ads / shop / live` + 当天日期。
- 平台名 + `规则 / 算法 / 达人 / 广告 / 直播 / Shop` + 当天日期。
- 美国、欧洲、东南亚、中东和拉美的区域语言关键词。

## 入选顺序

每条候选先过当天性，再判断：

- 岗位相关性：是否直接影响内容运营动作。
- 紧迫性：是否需要今天调整账号、内容、达人或广告。
- 可执行性：能否给出明确的检查或测试动作。
- 来源强度：官方原始来源优先；二手信息不能单独支撑高置信度结论。
- 来源多样性：同一平台或同一官方来源原则上最多占今日核心的 2 条；超过 2 条必须分别属于当天独立发生的重大事件，并明确说明集中原因。
- 新颖性：是否未在历史日报覆盖，或出现新的生效/落地证据。

## 强制排除

- 纯物流、货运、海外仓、清关和支付新闻。
- 普通门店开业、加盟、融资、组织任命和泛市场扩张。
- 只有“全球化”“出海”“跨境”等关键词但不影响内容工作的文章。
- 搜索结果当天出现、实际事件发生在更早日期的旧稿。
- 没有原始依据的“算法大改”“流量暴涨”“平台内部消息”。

## 发布闸门

- `content/latest.json` 的 `report_date` 必须等于北京时间当天。
- 每条核心资讯必须包含事件日期/状态、类别、行动建议、来源和置信度。
- 未通过当天核验时，网站构建失败并保留上一期可靠页面。
- 当天没有任何条目通过核验时，允许发布 0 条，并在页面明确说明“今日无通过核验的核心资讯”；禁止用背景跟踪填入核心卡片。
