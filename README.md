# 品牌出海热点速递

这是一个可发布到 GitHub Pages 的每日资讯网站。上线后，你只需要打开网站地址，就能看到每天自动生成的品牌出海热点。

## 它会做什么

- 每天北京时间 21:30 在后台预采集，次日 9:30 合并过去24小时候选并发布唯一晨报；晚间不会短暂改写网页。
- 优先覆盖平台大动作、内容趋势、达人/KOL、广告投放、TikTok Shop 与代表性品牌内容案例。
- 六类信息仅作为热点卡片的分类标签和配图规则，不在页面重复展示固定模块。
- 网站优先读取 `content/latest.json` 中经过日期、来源和历史去重核验的日报。
- `已核验事实`采用“上一日9:30—当日9:30”的全球24小时窗口，并保留来源当地时间与北京时间换算；晚间候选会自动并入次日晨报，跨时区消息不会漏掉或被晨报覆盖。
- 只有当天`已核验事实`为 0 条时，才启动带具体发布日期和原文链接的`行业雷达`（国内公众号、海外创作者或行业媒体）；两类信息不在同一天混发。行业雷达会在卡片上单独标注，不能被写成官方已确认事实。
- 行业雷达常规只看过去48小时，极端情况下扩展到72小时且最多补录1条；同一事件14天内不重复，除非出现实质进展。
- 每期日报会沉淀为按日期保存的结构化归档；网站的“沉淀库”页面会呈现每日档案，以及季度末、年末生成的总结。
- 当天没有任何合格内容时，页面会明确显示 0 条，不会用RSS、旧闻或固定占位稿补位。
- 生成一个可直接访问的网页：`public/index.html`。
- 只展示摘要、来源和链接，不转载全文。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `brand-global-news`。
2. 把本目录里的文件上传到这个仓库。
3. 打开仓库的 `Settings`。
4. 进入 `Pages`。
5. 在 `Build and deployment` 里选择 `GitHub Actions`。
6. 打开仓库的 `Actions`，手动运行一次 `Daily Brand Global News`。
7. 运行成功后，GitHub Pages 会给出网站地址。

GitHub Actions 不再用固定占位稿伪装成当天新闻；没有可发布内容时会明确失败，保留上一期可靠日报。

## 本地预览

如果只想先在电脑上看效果，可以运行：

```bash
python scripts/generate_site.py
```

然后打开：

```text
public/index.html
```

## 注意

这个网站默认是公开的。不要把账号、密钥、内部策略、客户名单或任何不希望公开的信息放进网页内容里。
